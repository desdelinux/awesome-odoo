# Awesome Odoo [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

Odoo is a suite of open-source business applications covering CRM, sales,
accounting, inventory, manufacturing, project management, and more.

Inspired by [awesome-python](https://github.com/vinta/awesome-python).

## Tools

### All-in-one Tools

- [Doodba](https://github.com/tecnativa/doodba) - Docker base image that makes
  creating customized Odoo environments easy.
- [odoo-tools](https://github.com/llacroix/odoo-tools) - Generic library that
  simplifies managing Odoo environments.

### Search Engines

- [Odoo Code Search](http://www.odoo-code-search.com/) - Searchable index of
  Odoo source code.

### Scripts

- [Odoo Install Script](https://github.com/Yenthe666/InstallScript) - Install
  script by Yenthe Van Ginneken.
- [Odoo Module Packaging](https://gist.github.com/josehbez/b14bb8b7dd6c0c985a96e57cff7cef5a) - Python
  script that compresses an Odoo module and its dependencies into a ZIP
  file.
- [Odoo Module Community](https://gist.github.com/josehbez/a0790e91bd807ca174834fb67c3e0e8c) - Script
  for publishing modules from a private repository to a public read-only
  repository.
- [Odoo Graph Dependency](https://medium.com/@josehbez/dependencia-gr%C3%A1fica-odoo-e518e8a6ceb9) - Python
  script that visualizes the dependency graph of a module.
- [Odoo Backup](https://medium.com/@josehbez/simple-cli-odoo-backup-60d91bc3b9ec) - Python
  script that uses the `/web/database/backup` endpoint to generate
  backups.

### Libraries

- [ERPPeek](https://pypi.python.org/pypi/ERPpeek) - Low-level API and Active
  Record encapsulation, plus helpers to administer the server remotely
  ([docs](http://erppeek.readthedocs.org)).
- [OdooRPC](https://github.com/OCA/odoorpc) - Python module to pilot Odoo
  servers through JSON-RPC.

### IDEs

- [Visual Studio Code](https://code.visualstudio.com/) - Code editor optimized
  for building and debugging modern web and cloud applications.
- [PyCharm](http://www.jetbrains.com/pycharm/) - Integrated development
  environment for Python.
- [Sublime Text](http://www.sublimetext.com/) - Sophisticated text editor for
  code, markup, and prose.
- [Spacemacs](https://github.com/syl20bnr/spacemacs) - Editor that combines
  Emacs with Vim.

### Report Engines

- [Aeroo Reports](https://github.com/aeroo/aeroo_reports) - Versatile reporting
  engine with Open/LibreOffice integration
  ([docs](http://www.alistek.com/wiki/index.php/Main_Page)).
- [Pentaho Reports](https://github.com/WillowIT/Pentaho-reports-for-OpenERP) - Runs
  Pentaho reports in Odoo and designs them with the Pentaho report designer
  ([docs](https://github.com/WillowIT/Pentaho-reports-for-OpenERP/wiki),
  [presentation](http://www.slideshare.net/openobject/openerp-pentaho-integration-willowit)).
- [Jasper Report Server](https://github.com/mga-team-odoo/jasperserver) - Composes
  reports with iReport or JasperStudio and defines printing actions in
  Odoo.
- [Birt Reports](https://github.com/vaab/report_birt) - Uses the
  [Birt Viewer](http://eclipse.org/birt/documentation/integrating/viewer-setup.php)
  to generate reports.

### CLI

- [click-odoo](https://github.com/acsone/click-odoo) - Runs Python scripts in an
  Odoo environment.
- [click-odoo-contrib](https://github.com/acsone/click-odoo-contrib) - Useful
  scripts and utility functions based on click-odoo.

### Linters

- [pylint-odoo](https://github.com/OCA/pylint-odoo) - Pylint plugin for Odoo.

### Design

- [odoo-fa-icons](https://docs.huihoo.com/odoo/training/reference-material/odoo-icon-smart-buttons.pdf) - Icons
  for buttons.
